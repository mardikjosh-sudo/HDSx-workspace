# Provenance and stewardship note

The dataset is the prepared `nhanes_equity_v6.csv` classroom snapshot derived
from public-use NHANES files maintained by the CDC/NCHS.

The source of the underlying records is the public NHANES program, while this
prepared file is cached in the course repository for reproducible offline
classroom work.

The access method for this analysis is the repository-relative CSV path
`examples/nhanes-equity/data/nhanes_equity_v6.csv`.

The file is intended for descriptive classroom learning and should not be
treated as an individual-level clinical or population-representative analysis
without the appropriate survey design and weights.

As a privacy and stewardship precaution, do not upload row-level records from
this snapshot to external AI tools or make small-cell claims from the
classroom summary.
